# KeyStepPro Studio v0.4.0

Generator styles and drum patterns.

## Highlights

- **Generate... with styles**: besides Ambient (Classic, Ethereal, Dark, Meditative) there are **Techno** (Driving), **House** (Deep, Chill, Melodic) and **Drum & bass** (Liquid). A style puts track 1 in drum mode with a groove (the last variation ends with a fill) and writes bass, chords and a lead on tracks 2-4, plus the scenes. It also sets the **project tempo** (techno 130, house 118-128, drum & bass 174 BPM). The window shows a magic wand so it is easy to find.
- **Drum grid**: when track 1 is in drum mode, the grid shows 24 drum lanes named after the KeyStep's default General MIDI drum map (kick 36, snare 38, clap 39, hats 42 and 46, ...). Click to add or remove hits, drag to paint, and use the mouse wheel to set velocity. Click a lane name to hear it.
- **Drums** switch on track 1's card (drum or sequencer mode; both kinds of patterns stay stored) and **Clear** to empty the pattern shown.
- In drum mode, the track 1 instrument listens on the drum channel (10), so a General MIDI style kit or an Ableton Drum Rack plays without remapping.
- Drum pattern writes verified on a KeyStep Pro (firmware 2.5.20) with a full read-back.
- Easier to use: a click anywhere on a track card selects it, with a hand pointer over the cards you can select; the number is centred on its dot; **FX...** is on the top bar.

## Install

Download `KeyStepProStudio-Setup-0.4.0.exe`, run it and start **KeyStepPro Studio**. Connect the KeyStep Pro by USB and close MIDI Control Center first.

The installer is **not code-signed**, so Windows SmartScreen shows "Windows protected your PC": click **More info**, then **Run anyway**. Check the download against `SHA256SUMS.txt`:

```
Get-FileHash .\KeyStepProStudio-Setup-0.4.0.exe -Algorithm SHA256
```

## Safety

Writes only to a KeyStep Pro on firmware 2.5.20, with an automatic backup before every write and a read-back after. Make a full backup before you start. No warranty.
