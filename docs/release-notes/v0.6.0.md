# KeyStepPro Studio v0.6.0

The arpeggiator, tempo and swing, per-track MIDI channels, pattern ops and redesigned track cards.

## Highlights

- **Arpeggiator** (tracks 2-4): on/off, mode (Up, Down, Exclu, Inclu, Rand, Order, Poly), octave, swing and division, decoded on a real KeyStep Pro.
- **Track cards**: taller, with Seq / Arp keys (Seq / Drum on track 1), a vertical volume slider, M and S keys, a plugin icon key and a glow on what is on. Clicking any control selects the card.
- **Tempo and swing** of the project, and a **MIDI channel per track** (Auto or 1-16), in the Project Map.
- **Ops** button: nudge left / right, reverse and invert the pattern.
- **Project Map**: editable chains in the Scene Matrix, drum patterns shown for track 1 in drum mode, scene mute.
- **Generate** puts tracks 2-4 back in Seq (a track in Arp mode only arpeggiates the keys you hold, so it would not play the generated patterns), and says that the scenes it writes have no mutes.
- **Per-track MIDI channels reach the instruments**: each track's VST3 listens on the track's channel from the project, or 1-4 (drums 10) on Auto.
- **Drum grid**: the END line has a grip to drag, and the STEPS display shows the drum pattern's length.
- **Write uploads the whole open project.** If you changed the KeyStep by hand after the last Read, Read first; the backup taken before every Write keeps the previous state.

## Install

Download `KeyStepProStudio-Setup-0.6.0.exe` (or the portable zip), run it and start **KeyStepPro Studio**. Connect the KeyStep Pro by USB and close MIDI Control Center first.

The installer is **not code-signed**, so Windows SmartScreen shows "Windows protected your PC": click **More info**, then **Run anyway**. Check the download against `SHA256SUMS.txt`:

```
Get-FileHash .\KeyStepProStudio-Setup-0.6.0.exe -Algorithm SHA256
```

If Windows Defender flags the installer (a machine-learning false positive on unsigned files), use the **portable zip**.

## Safety

Writes only to a KeyStep Pro on firmware 2.5.20, with an automatic backup before every write and a read-back after. Make a full backup before you start. No warranty.
