# KeyStepPro Studio v0.7.0

Two editions from one source tree. **Lite is the recommended one**: it is the editor, nothing else. **Full** is the same editor plus VST3 hosting.

## Which one do I download?

| | Lite (recommended) | Full |
| --- | --- | --- |
| Edit patterns, drums, scenes, chains, arp, tempo, swing, MIDI channels | yes | yes |
| Read / write the KeyStep over USB, backups, library, generator, MIDI monitor | yes | yes |
| KeyStep clock readout (Play/Stop, position, BPM) | yes | yes |
| VST3 instruments and effects per track, audio output, WAV recording | no | yes |
| Installer | `KeyStepProStudio-Setup-0.7.0.exe` | `KeyStepProStudio-Full-Setup-0.7.0.exe` |
| Portable zip | `KeyStepProStudio-0.7.0-portable.zip` | `KeyStepProStudio-Full-0.7.0-portable.zip` |
| macOS zip | `KeyStepProStudio-0.7.0-mac.zip` | `KeyStepProStudio-Full-0.7.0-mac.zip` |

Both are maintained. The editions replace each other if you install one over the other. Lite does not make sound: play the KeyStep through its own outputs or your DAW.

## What changed
- New **Lite** edition (no VST3 SDK, no plugin helper). CMake option `KSP_ENABLE_VST_HOST` (OFF = Lite, ON = Full).
- **Rec (overdub) removed** in both editions: it only recorded the echo of the KeyStep's own sequencer.
- Lite: Seq / Arp / Drum keys are lit correctly when a project loads.
- Library: double click or Enter opens a project, and the window closes after opening.
- New track card chapter in the manual; screenshots refreshed.
- Installer and CI build both editions (Windows and macOS).

## Install
Unsigned: SmartScreen will warn ("More info" > "Run anyway"). SHA-256 sums: `SHA256SUMS.txt` (Lite) and `SHA256SUMS-Full.txt`. VirusTotal links: _to add after upload_. Close MIDI Control Center before connecting. Only official firmware 2.5.20 is written to, with a backup before each write and a read-back check.

macOS: `KeyStepProStudio-0.7.0-mac.zip` (Lite) and `KeyStepProStudio-Full-0.7.0-mac.zip` (Full), universal (Apple silicon and Intel), macOS 11+. Ad-hoc signed, not notarized: first launch with right-click > Open. Each zip has a `.sha256` file.
