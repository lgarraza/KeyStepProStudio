# KeyStepPro Studio v0.5.0

A musical Generate: scenes with an energy curve, your own key and scale, and a clearer Project Map.

## Highlights

- **Musical arrangement** (Generate, Techno, House and Drum & bass; on by default): eight scenes with an energy curve (intro, groove, drop, drop variation, breakdown, build, peak, outro). Track 1 gets five drum patterns, tracks 2-4 get twelve (four energy levels x three chords), and pattern 16 is empty on every track to silence a track in a scene. No role pattern comes out silent.
- **Key and Scale** in Generate: pick them or leave **Auto** (the style's own). The description under the style follows your choice.
- **Clearer Generate**: a plain-language note under the seed box, and the window and the status line say which track plays what (drums, bass, chords, lead).
- **Clean track 1**: a style leaves the sequencer patterns of track 1 empty, so switching **Drums** off shows clean patterns in the style's key; Ambient puts track 1 back in sequencer mode.
- **Project Map**: click a scene number to select it. Its column stays marked, the side panel shows the whole scene (each track's chain and how many bars it lasts), and the editor shows the pattern the selected track plays in it. Clickable things show a hand cursor.
- **Write** shows one progress bar for backup, write and read-back.
- **Tools menu fix**, **macOS build in CI**, and the VST3 helper is now called `KspVstHelper`.
- **Hardware**: a pattern with no kick reads back one drum value as unreadable on the KeyStep; the read-back check now accepts it, so `KspGen` no longer reports an error.

## Install

Download `KeyStepProStudio-Setup-0.5.0.exe` (or the portable zip), run it and start **KeyStepPro Studio**. Connect the KeyStep Pro by USB and close MIDI Control Center first.

The installer is **not code-signed**, so Windows SmartScreen shows "Windows protected your PC": click **More info**, then **Run anyway**. Check the download against `SHA256SUMS.txt`:

```
Get-FileHash .\KeyStepProStudio-Setup-0.5.0.exe -Algorithm SHA256
```

If Windows Defender flags the installer (a machine-learning false positive on unsigned files), use the **portable zip**.

## Safety

Writes only to a KeyStep Pro on firmware 2.5.20, with an automatic backup before every write and a read-back after. Make a full backup before you start. No warranty.
