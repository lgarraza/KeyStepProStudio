# KeyStepPro Studio v0.4.1

Scene editing in the Project Map, the user manual as a PDF, and a portable zip.

## Highlights

- **Edit scenes in the Project Map**: click a cell of the Scene matrix and pick the pattern (1-16) that track plays in that scene, or remove the cell's chain. Right-click a scene number to **Copy**, **Paste** or **Clear** it. **Undo edit** takes back the last change. Edits go to the open project; use **Save** and **Write** as usual.
- **User manual as a PDF**: `KeyStepPro-Studio-Manual.pdf` is installed next to the app (and is in the zip). Open it from **Tools > User manual (PDF)**.
- **Portable zip**: `KeyStepProStudio-0.4.1-portable.zip` holds the same files as the installer. Unzip it anywhere and run `KeyStepPro Studio.exe`.
- `SHA256SUMS.txt` lists both files.

## Install

Download `KeyStepProStudio-Setup-0.4.1.exe` (or the portable zip), run it and start **KeyStepPro Studio**. Connect the KeyStep Pro by USB and close MIDI Control Center first.

The installer is **not code-signed**, so Windows SmartScreen shows "Windows protected your PC": click **More info**, then **Run anyway**. Check the download against `SHA256SUMS.txt`:

```
Get-FileHash .\KeyStepProStudio-Setup-0.4.1.exe -Algorithm SHA256
```

## Windows Defender warning

Some Windows Defender versions flag the new, unsigned installer as `Trojan:Win32/Wacatac.C!ml`. That is a machine-learning false positive, not a virus signature, and it has been reported to Microsoft. Until it is cleared, use the **portable zip**, which scans clean. You can check any file against the VirusTotal links and SHA-256 hashes below.

## Safety

Writes only to a KeyStep Pro on firmware 2.5.20, with an automatic backup before every write and a read-back after. Make a full backup before you start. No warranty.
