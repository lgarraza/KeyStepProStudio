# KeyStepPro Studio v0.3.0

First public release of the new repository.

## Highlights

- **Project dropdown with Read and Write** in the top row: pick a KeyStep project and read it, or write the open project back, with a progress popup while it works.
- **Project Map**: scenes by tracks with a mini piano roll per cell, chain timeline and pattern bank (read-only).
- **Note names** on the grid keys and on the notes, with rows tinted in the pattern's scale.
- Pattern editor, library, VST3 host (one instrument per track, inserts and master chain), WAV recording, ambient generator and backups, as described in the [user guide](../manual/user/README.md).

## Install

Download `KeyStepProStudio-Setup-0.3.0.exe`, run it and start **KeyStepPro Studio**. Connect the KeyStep Pro by USB and close MIDI Control Center first.

The installer is **not code-signed**, so Windows SmartScreen shows "Windows protected your PC": click **More info**, then **Run anyway**. Check the download against `SHA256SUMS.txt`:

```
Get-FileHash .\KeyStepProStudio-Setup-0.3.0.exe -Algorithm SHA256
```

VirusTotal scan: _link to add when the release is published._

## Safety

Writes only to a KeyStep Pro on firmware 2.5.20, with an automatic backup before every write and a read-back after. Make a full backup before you start. No warranty.
